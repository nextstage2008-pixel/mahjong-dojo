# やっしーGAMES 麻雀道場

判断の質を磨く、麻雀の練習ゲームです。CPU 3人と打ち、指南と採点・感想戦・問題集・道場（講義と練習問題）で上達します。

- 遊ぶ：https://nextstage2008-pixel.github.io/mahjong-dojo/
- スマホは、ホーム画面に追加すると電波がなくても遊べます（iPhone は Safari の共有のボタン（□に↑）→「ホーム画面に追加」、Android は Chrome のメニュー（︙）→「ホーム画面に追加」）

## お金を賭けません

点数はゲームの中だけのものです。換金や景品はありません。賭け麻雀とは関係がなく、勧めもしません。

## 記録

記録（対局の続き・道場・問題集）はその端末のブラウザの中だけに置き、どこにも送りません。iPhone の Safari のタブとホーム画面では記録が別なので、最初からホーム画面に追加して遊んでください。
